# 課程資料說明

本目錄只放課程合成資料或可正式公開的課程產物，不含病人、學生、客戶、員工、契約或未公開研究資料。

12 份 CSV 全數由課程發布產生器以固定 seed 直接重建，不從既存資料檔複製到公開包。每一列都是合成紀錄；咖啡會員、交易編號與健檢編號皆為人工碼，不對應真實人物。產生器、seed、schema、筆數、欄位、精確 SHA-256、是否移除挑戰標籤與來源模組雜湊，均記錄於 `SYNTHETIC_DATA_PROVENANCE.json`。

四份結構參考資料只保留教學任務所需的 schema、筆數與模擬關係，沒有再散布 ISLP 或其他來源的原始資料列。所有資料只用來練習描述、推論與預測流程，不代表真實族群；只有 `coffee_ab_test.csv` 是合成的隨機分派示範，仍不可外推成真實菜單效果。
